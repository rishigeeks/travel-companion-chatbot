# Wanderlust - AI Travel Companion

Wanderlust is a premium, non-hallucinating travel chatbot built with Python (Flask) and Google's Gemini 1.5 Flash.

## Features
- **Zero Hallucination**: Uses function calling to fetch real-world data about restaurants and events.
- **Premium UI**: Modern dark-mode interface with glassmorphism effects.
- **Factual Tips**: Reliable travel etiquette and cultural advice for major cities.

## How to Run
1. Clone the repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Create a `.env` file with your `GEMINI_API_KEY`.
4. Run the app: `python app.py`
